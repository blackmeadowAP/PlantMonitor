# 06. Аналитика и отчёты

Все числа считает код (SQL / Python) в `core/services/stats.py`. Языковая модель только пишет текст по готовым фактам (docs/07).

## Формулы

| Показатель | Формула | Где хранится |
| --- | --- | --- |
| Распространённость поля, % | Σ plants_affected / Σ plants_inspected × 100 по наблюдениям поля за окно [D−3; D] | daily_field_stats.prevalence_pct |
| Распространённость по болезни | то же, но только по наблюдениям с действующей разметкой verdict = disease и данной болезнью; иначе — общая | считается в отчёте |
| Развитие болезни, балл | среднее severity действующих оценок verdict = disease за окно | daily_field_stats.severity_avg |
| Скорость, п.п./сут | (prevalence(D) − prevalence(D−7)) / 7; если D−7 нет — по самой ранней точке окна, делённой на фактическое число дней; < 2 точек → null | daily_field_stats.speed_pp_day |
| Тренд | up при speed > +0,5; down при speed < −0,5; иначе flat; null при отсутствии данных | daily_field_stats.trend |
| Свежесть данных | now − max(taken_at) по полю | last_photo_at |
| Эффект обработки | prevalence до обработки (последнее значение ≤ даты) и через 5–7 дней после | в отчёте |
| Выполнение заданий, % | tasks done / tasks total за день (неделю) | daily_user_stats |
| Качество снимков, % | photos quality_ok и без «Переснять» / все фото | daily_user_stats |
| Точность привязки, м | среднее distance_m | daily_user_stats |
| Время до разметки | среднее (assessment.created_at − observation.taken_at) | в отчёте агронома |

Пороги (0,5 п.п./сут, окно 3 дня, 7 дней для скорости) — константы в `core/config.py`, изменения фиксировать в 10_DECISIONS.

## Статус предприятия на карте

1. **Серый** — нет ни одного фото за последние 24 ч.
2. **Красный** — есть активный очаг на поле с trend = up.
3. **Жёлтый** — есть активные очаги без роста или неразобранные подозрения (verdict = suspect за 3 дня).
4. **Зелёный** — иначе.

Стрелка тренда предприятия — по полю с максимальной скоростью. Карточка: культуры, болезни (активные очаги), средняя распространённость по полям с очагами, скорость, дата последнего фото, % выполнения заданий за 7 дней.

## Техника формирования PDF

`reports/facts.py` → dict фактов (+ `facts_hash` для кэша) → `reports/llm.py` (опционально) → `reports/templates/*.html` (Jinja2) →
графики `reports/charts.py` (matplotlib → PNG base64) → карта `reports/maps.py` (staticmap, тайлы OSM, кэш) → WeasyPrint → PDF → S3 `reports/{scope}/{scope_id}/{period}.pdf` → `send_document`.
Шрифт с кириллицей (DejaVu Sans или PT Sans) — в образе.
