# 08. План разработки (roadmap)

Правило: один шаг = одна сессия агента = один коммит. Агент отмечает шаг `[x]` после прохождения проверки.
Запуск шага — главным промптом из гайда с подстановкой номера: «…найди шаг {N}…».
Модель: **[pro]** — сложный шаг (сильная модель), **[flash]** — рутинный.

---

## [ ] Шаг 1. Каркас проекта [pro]
**Читать:** AGENTS.md, 02_ARCHITECTURE.md
**Сделать:** `pyproject.toml` (зависимости из AGENTS.md), `Dockerfile` (python:3.12-slim + системные библиотеки для WeasyPrint и OpenCV), `docker-compose.yml` (db, redis, minio, app, bot, api, worker), структура папок, `core/config.py` (pydantic-settings), `core/db.py`, логирование, ruff, pytest с тестовой БД, `bot/__main__.py` с `/ping`, `api/main.py` с `/health`, GitHub Actions (ruff + pytest).
**Проверка:** `docker compose up` без ошибок; бот отвечает на `/ping`; `curl localhost:8000/health` → ok; `pytest` зелёный.

## [ ] Шаг 2. База данных и тестовые данные [pro]
**Читать:** 03_DATA_MODEL.md
**Сделать:** все модели SQLAlchemy, первая миграция Alembic (включая `CREATE EXTENSION postgis`), `scripts/seed.py`, `scripts/create_admin.py`.
**Проверка:** таблицы в DBeaver; seed создаёт данные и печатает коды; тест: точка в 30 м от заданной → `ST_Distance` ≈ 30.

## [ ] Шаг 3. Регистрация, роли, меню [pro]
**Читать:** 01_PRODUCT_SPEC.md (ОБ-1, ОБ-2), 04_BOT_FLOWS.md (Регистрация, Меню)
**Сделать:** middleware загрузки пользователя, `/start <код>`, согласие, меню по ролям, создание кодов (суперпользователь → агроном, агроном → работник, админ → суперпользователь), `core/services/access.py`.
**Проверка:** 3 аккаунта видят 3 разных меню; код не срабатывает повторно; тесты прав доступа.

## [ ] Шаг 4. Поля и точки [flash]
**Читать:** 04_BOT_FLOWS.md (Поля и точки), А-1, А-2
**Сделать:** добавление поля, точек, закрепление за работником, просмотр списка, режим «ежедневно».
**Проверка:** поле и точки в БД с верными координатами; агроном не видит поля другого предприятия.

## [ ] Шаг 5. Задания [pro]
**Читать:** 04_BOT_FLOWS.md (Задания), 02_ARCHITECTURE.md (Расписание)
**Сделать:** `core/services/tasks.py` (генерация по приоритетам, лимит 10), cron 06:30/07:00/15:00/23:30, команда админа «сгенерировать сейчас».
**Проверка:** тесты на приоритеты и лимит; ручной запуск → работнику пришло задание.

## [ ] Шаг 6. Съёмка точки [pro]
**Читать:** 05_PHOTO_PROTOCOL.md, 04_BOT_FLOWS.md (съёмка), Р-2…Р-6
**Сделать:** FSM `Shoot`, геопроверка, счётчик 0…10, 3+1 фото, `core/images.py` (качество), `core/storage.py` (архив-канал + S3), «Заметил проблему», уведомление агроному о внеплановом.
**Проверка:** размытое фото отклоняется; фото дальше 50 м не принимается; файлы в MinIO и в канале; при остановленном MinIO фото всё равно сохраняется (s3_key = null) и догружается после запуска.

## [ ] Шаг 7. Разметка, очаги, сообщения [pro]
**Читать:** 04_BOT_FLOWS.md (разметка, очаг, сообщения), А-4, А-6, ОБ-3
**Сделать:** FSM `Label`, выбор болезни и балла, «Переснять», очаги (создание, обновление, обработка, закрытие), точка focus, кнопка «Ответить», `keep_forever`.
**Проверка:** разметка точки ≤ 3 нажатий; очаг появляется в завтрашних заданиях; ответ доходит с контекстом.

## [ ] Шаг 8. Показатели [pro]
**Читать:** 06_ANALYTICS_AND_REPORTS.md (Формулы, Статус)
**Сделать:** `core/services/stats.py`, пересчёт по событиям и по cron 17:45, статус предприятия, «Требует внимания», «Работники».
**Проверка:** тесты на 5+ ручных примерах (в т. ч. нет данных, одна точка, рост, падение); цифры совпадают с расчётом на бумаге.

## [ ] Шаг 9. Сводки и PDF без ИИ [flash]
**Читать:** 06_ANALYTICS_AND_REPORTS.md (Шаблоны А и Б, Техника)
**Сделать:** `reports/facts.py`, шаблоны Jinja2, графики, карта-картинка, WeasyPrint, сводки 18:00 и 19:00, кнопки PDF.
**Проверка:** PDF открывается, кириллица корректна, цифры совпадают с БД; PDF ≤ 2 мин.

## [ ] Шаг 10. Карта Mini App [flash]
**Читать:** С-2, А-10, 02_ARCHITECTURE.md (Карта)
**Сделать:** `api/auth.py` (проверка initData по HMAC), эндпоинты GeoJSON, `webapp/` (Leaflet, цвета статусов, стрелки, карточка, фильтры), кнопка WebApp в меню, сервис `tunnel` в compose.
**Проверка:** карта открывается в Telegram на телефоне; агроном не может запросить чужое предприятие (тест API); подделанный initData → 401.

## [ ] Шаг 11. Нейросеть [pro]
**Читать:** 07_ML_AND_LLM.md (Часть 1)
**Сделать:** `ml/train/*` (обучение на открытых данных), `ml/local.py`, `ml/client.py`, `ml/space_app/`, задача `predict_photo`, подсказка в ленте, сортировка ленты.
**Проверка:** на своих фото подсказки разумные; `ML_MODE=off` и недоступный Space не ломают бота; model_card.md с метриками.

## [ ] Шаг 12. ИИ-резюме отчётов [pro]
**Читать:** 07_ML_AND_LLM.md (Часть 2)
**Сделать:** `reports/llm.py` (промпт, JSON-схема, валидация чисел, повтор, резервный текст, кэш), сервис `ollama` в compose, включение `LLM_ENABLED`.
**Проверка:** 20 сгенерированных отчётов без выдуманных чисел (автотест на проверку); при выключенном LLM отчёты формируются.

## [ ] Шаг 13. Развёртывание пилота [pro]
