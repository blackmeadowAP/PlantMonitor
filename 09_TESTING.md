# 09. Тестирование

## Автотесты (pytest)

Обязательные области — без них шаг не считается выполненным:

| Модуль | Что проверять |
| --- | --- |
| core/geo.py | расстояние до точки (0, 30, 49, 51, 300 м); привязка внепланового фото к ближайшей точке / полю |
| core/images.py | резкое / размытое / тёмное / пересвеченное / маленькое фото (фикстуры в tests/data/) |
| core/services/tasks.py | приоритеты focus > risk > regular; interval_days; daily_mode; лимит 10; перенос missed |
| core/services/access.py | агроном ↔ чужое предприятие; работник ↔ чужие задания; суперпользователь ↔ чужая область; деактивированный пользователь |
| core/services/stats.py | распространённость, скорость, тренд, статус предприятия; пустые данные; одна точка |
| reports/llm.py | валидация: лишнее число → отказ; корректный текст → принят; падение LLM → резервный текст |
| api/auth.py | валидный / подделанный / просроченный initData |
| storage | недоступный S3 → фото сохранено в БД и архиве, задача повтора поставлена (mock) |

Тесты работают с тестовой БД PostGIS (отдельный сервис `db_test` в compose или testcontainers). Telegram — через моки aiogram (без реальной сети).

## Ручной чек-лист перед пилотом (критерии приёмки)

- [ ] Работник без обучения снимает точку ≤ 2 мин.
- [ ] Фото дальше 50 м не принимается; размытое — просьба переснять.
- [ ] Агроном размечает точку ≤ 3 нажатий.
- [ ] Подтверждённый очаг виден на карте суперпользователя ≤ 5 мин.
- [ ] Цифры в PDF совпадают с контрольным расчётом.
- [ ] В ИИ-резюме нет чисел и названий, отсутствующих в фактах (20 отчётов).
- [ ] Агроном не видит чужие предприятия, в т. ч. через API.
- [ ] После перезапуска сервера фото, отправленные во время простоя, не потеряны.
- [ ] База восстанавливается из бэкапа на чистом сервере.

## Тестовые данные

`tests/data/`: 10 резких и 5 размытых фото листьев, 2 тёмных, 1 пересвеченное, 1 маленькое (800 px).
`scripts/seed.py` — территориальные справочники, 2 предприятия, поля и точки; `scripts/simulate_week.py` (шаг 8) — генерация наблюдений за 7 дней с растущим очагом для проверки трендов и отчётов.
