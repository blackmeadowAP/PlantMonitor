# Agro Monitor

Система оперативного сбора данных о болезнях сельскохозяйственных культур:
Telegram-бот для работников и агрономов, карта области и PDF-аналитика для руководства.

## Как пользоваться этим пакетом документации

1. Создайте пустой приватный репозиторий и скопируйте в его корень всё содержимое этого архива
   (документы лежат в `docs/`, `AGENTS.md` и `README.md` — в корне).
2. Скопируйте `.env.example` в `.env` и заполните (как минимум `BOT_TOKEN` тестового бота).
3. Откройте папку в VS Code с ИИ-агентом (например, Cline) и начните с шага 1 из `docs/08_ROADMAP.md`,
   используя главный промпт из гайда (вкладка «Гайд по вайбкодингу» в документе концепции).
4. После каждого шага: проверка руками → `pytest` → git commit.

## Структура документации

- `AGENTS.md` — правила для ИИ-агента (стек, запреты, порядок работы).
- `docs/01_PRODUCT_SPEC.md` … `docs/10_DECISIONS.md` — требования, архитектура, данные, сценарии, формулы, план, тесты, журнал решений.

## Быстрый запуск (появится после шага 1)

```bash
cp .env.example .env
docker compose up -d
docker compose run --rm app alembic upgrade head
docker compose run --rm app python -m scripts.seed
```
