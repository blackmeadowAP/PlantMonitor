# 04. Сценарии бота

Общие правила: кнопки вместо ввода текста; одно действие — одно сообщение; после ошибки — понятная подсказка и кнопка повтора.
Все тексты — в `bot/texts.py`. Геопозиция запрашивается reply-кнопкой `KeyboardButton(request_location=True)`.

## Регистрация (все роли)

1. `/start <код>` → проверка кода (существует, не использован, не истёк).
2. «Введите фамилию и имя» → сохранение.
3. Согласие на обработку персональных данных (кнопки «Согласен» / «Отмена»).
4. Приветствие + меню роли. Код помечается использованным.
5. `/start` без кода у незарегистрированного → «Попросите код у агронома или администратора».

## Меню

- **Работник:** «Моё задание» · «Заметил проблему» · «Как снимать» · «Сообщение агроному»
- **Агроном:** «Разметить фото (N)» · «Требует внимания» · «Поля и точки» · «Очаги» · «Работники» · «Отчёт» · «Карта» · «Пригласить работника»
- **Суперпользователь:** «Карта области» · «Сводка» · «Скачать PDF» · «Предприятия» · «Рассылка» · «Пригласить агронома»
- **Администратор:** «Справочники» · «Создать суперпользователя» · «Состояние системы»

## Работник: съёмка точки (FSM `Shoot`)

1. «Моё задание» → список точек дня: «Поле №3, точка 2 (риск) — не снята» + кнопка «Начать».
2. «Начать» → бот присылает location точки и просит «Когда будете на месте, нажмите „Я на месте“» (reply-кнопка геопозиции).
3. Получена геопозиция → расстояние до точки. Если > `GEO_MAX_DISTANCE_M` → «Вы в N м от точки. Подойдите ближе» (повтор). Иначе → шаг 4.
4. «Осмотрите 10 растений подряд в ряду. Сколько с пятнами или налётом?» → кнопки 0…10.
5. «Шаг 1 из 3: общий план» + образец (фото из справочника) → приём фото → проверка качества (≤ 3 с). Плохо → «Фото размыто/тёмное, переснимите». Хорошо → шаг 2.
6. «Шаг 2 из 3: растение целиком» → аналогично.
7. «Шаг 3 из 3: крупный план листа (лучше „без сжатия“)» → аналогично. Принимаются и photo, и document (image/*).
8. Если на шаге 4 > 0 → «Снимите обратную сторону листа или стебель (по желанию)» + «Пропустить».
9. Кнопки «Листья мокрые» (переключатель) и «Готово» / «Добавить комментарий».
10. «Готово» → «Точка сохранена. Осталось N точек» → следующая точка.

Таймаут FSM — 2 часа; незавершённое наблюдение сохраняется с уже принятыми фото.

## Работник: «Заметил проблему»

Геопозиция → фото (1–3) → комментарий (необязательно) → сохраняется как `observation.is_unplanned = true`, привязка к ближайшей точке своего предприятия в радиусе 300 м или к полю по `ST_Contains(boundary)`. Агроному — уведомление сразу.

## Агроном: разметка (FSM `Label`)

1. «Разметить фото (N)» → альбом из фото одной точки (media group) + подпись: поле, точка, время, автор, «поражено 3/10», подсказка ИИ (если есть).
2. Кнопки: «Здорово» · «Подозрение» · «Болезнь» · «Переснять» · «Пропустить».
3. «Болезнь»/«Подозрение» → выбор болезни (список для культуры поля) → балл (0…max по шкале) → «Выехать/подтвердить позже» или «Подтверждено на месте».
4. «Переснять» → работнику сообщение «Агроном просит переснять точку …» + задача на сегодня.
5. Сортировка ленты: сначала подозрения работников (plants_affected > 0) и высокая вероятность болезни от ИИ, затем по времени.

## Агроном: очаг

«Очаги» → список активных → карточка: болезнь, поле, дата, динамика → «Обновить» (распространённость, балл) · «Обработка проведена» (препарат, норма, площадь) · «Закрыть очаг».
Подтверждение очага → точка `kind = focus` создаётся (или существующая меняет kind) → ежедневно в заданиях.

## Агроном: поля и точки

«Поля и точки» → список полей → «Добавить поле» (название → культура (кнопки) → площадь → геолокация центра) → «Добавить точку» (тип: плановая/риска → геолокация → работник (кнопки)) → «Режим: ежедневно все точки» (вкл/выкл).

## Задания (генерация в 06:30)

Для каждого работника — точки, закреплённые за ним, в порядке приоритета:
1. `focus` — всегда; 2. `risk` — всегда; 3. `regular` — если с последнего наблюдения прошло ≥ `interval_days`, или поле в `daily_mode`;
4. Перенос: `missed` вчера — в начало списка.
Лимит — 10 точек на работника в день (кроме `daily_mode`). Не попавшие точки помечаются в отчёте агронома.

## Суперпользователь

- «Сводка» → текст: предприятий с очагами (было/стало), новые очаги за сутки, топ-3 растущих, предприятия без данных > 24 ч; кнопка «Открыть карту».
- «Скачать PDF» → период (день / неделя / месяц / сезон) → «Готовлю отчёт…» → файл.
- «Рассылка» → кому (область / район / предприятия) → текст → подтверждение → отправка агрономам, запись в `messages`.

## Сообщения между ролями

Кнопка «Ответить» под любым уведомлением; ответ приходит адресату с контекстом («По точке 2, поле №3: …»).
